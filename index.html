The Greco AI Coder

TGAIC AI Coder

A lightweight, local-first AI coding assistant with a single-file browser UI, a PowerShell localhost bridge, llama.cpp integration, and Hugging Face GGUF model discovery.

TGAIC inference is designed to run locally. The hosted GitHub Pages site is the project/documentation entry point; the normal application workflow uses tgaic-ai-coder.html opened locally together with the bridge and llama-server.
GitHub / Setup & Docs Open Hosted UI

The hosted UI is provided for inspection/convenience; localhost browser security policies may prevent it from reaching a local HTTP bridge. The supported workflow is documented in the repository README.
